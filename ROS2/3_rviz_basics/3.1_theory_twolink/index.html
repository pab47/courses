3.1 Theory: twolink¶

The next two packages, 3.2 twolink and 3.3 twolink_ik, are ROS 2 wrappers around math taught in Lec04 and Lec05 of tiny.cc/robotics24. Watch these first — the ROS 2 code on the following pages will make a lot more sense once you've seen the plain-Python version of the same equations.

Lec04 — Forward Kinematics of a 2-Link Manipulator¶

3.2 twolink doesn't run any FK code of its own — robot_state_publisher and tf2 compute it for you from the URDF's joint angles and link lengths (l1, l2). Lec04 derives that same forward-kinematics chain by hand: two rotation-and-translation steps, one per revolute joint, composed to get the end-effector position. Worth watching before twolink_ik, since the inverse-kinematics solve there builds directly on this forward map.
Applies to 3.2 twolink

Lec05 — Inverse Kinematics of a 2D Manipulator¶

twolink_ik's kinematics.py (inverse_kinematics()) is the same numerical solve taught in Lec05: given a target (x_ref, y_ref), use forward_kinematics() inside a root-finder (fsolve) to search for the joint angles (theta1, theta2) that reach it, rather than deriving a closed-form solution. ik_node just runs that solve once at startup instead of interactively, as the lecture's script does.
