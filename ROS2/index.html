ROS 2 Tutorial¶

Pranav Bhounsule · tiny.cc/pranavb ·

Welcome! This site walks through ROS 2 (Jazzy) hands-on, using three small robot examples instead of toy "hello world" nodes:

  • ddrive — a differential-drive robot, used to teach core ROS 2 concepts (nodes, topics, publishers/subscribers, services, actions, parameters, launch files).
  • twolink — a two-link planar arm, used to teach RViz and forward / inverse kinematics.
  • dbpendulum — a double pendulum, used to teach Gazebo Sim physics and, later, torque control via ros2_control.

How the site is organized¶

  1. Installation — environment setup (ROS 2, workspace, dependencies).
  2. ROS2 Basics with ddrive — core concepts (nodes, topics, messages, publishers/subscribers, services, actions, parameters, packages, and launch files), then ddrive, ddrive_ik, and ddrive_ik_msgs (services & actions), finishing with an exercise (mecanum car).
  3. RViz Basics with twolink — twolink (joint-space sliders) and twolink_ik (Cartesian target tracking), finishing with an exercise (three-link IK with orientation).
  4. Gazebo Basics with dbpendulum — dbpendulum (passive, chaotic double pendulum) and dbpendulum_ctrl (feedback-linearization torque control), finishing with an exercise (single-pendulum swing-up).
