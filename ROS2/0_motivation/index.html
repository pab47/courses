Motivation¶

Why another ROS 2 tutorial?¶

There's no shortage of ROS 2 tutorials. The most common starting point is the one provided by ROS 2 itself:

  • Foxy Tutorials
  • Jazzy Tutorials
  • Lyrical Tutorials

These are complete — but complete also means long. You don't need to know everything in them to get a robot publishing and subscribing, moving in RViz, and falling under gravity in Gazebo.

This site is an attempt to make ROS 2 less intimidating by teaching only the essentials. There are just three things to get started:

  1. ROS 2 basics — nodes, topics, messages, publishers/subscribers, services, actions, parameters, packages, and launch files. This is the communication machinery that lets independent programs talk to each other.
  2. RViz — for visualization. This is the machinery to visualize a robot model built using the ROS 2 format, URDF.
  3. Gazebo — for simulation. This is the physics simulator that Gazebo provides.

Master those three, and you can read the official tutorials afterward for depth — instead of needing them just to get started.

Theory first, then ROS 2¶

There's an important distinction worth making explicit: anything implemented in ROS 2 can also be implemented yourself, from scratch, in any programming language. ROS 2 doesn't introduce new robotics theory — it gives existing theory (kinematics, control, simulation) a common communication and tooling layer so that independently-written nodes can work together.

To make that connection concrete, this tutorial takes a specific approach: concepts taught in my robotics course, tiny.cc/robotics24, and simulated in plain Python, are then converted into ROS 2 code. That way, students build and understand the robotics theory — kinematics, control, simulation — in a ROS-free system first, before seeing the same ideas wrapped in ROS 2. Accordingly, each section on this site includes a Theory subsection that points back to the relevant lecture notes from tiny.cc/robotics24.
