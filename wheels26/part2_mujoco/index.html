    Part 2: Introduction to MuJoCo¶

    For this section, you will need to install the mujoco package (see item 3 in the Equipment list).

    2.1 Basics of modeling / XML files (~3 hours)¶

    Material: Watch the video and practise coding as you watch it.

    https://youtu.be/WJa-FeFRl3Q

    The video uses this starter file: hello.xml

    At 0:48 in the video, I show how to use the model visualizer by downloading the app. An alternate way is to type the following in the terminal inside Visual Studio Code:

    python3 -m mujoco.viewer

    This will bring up the model visualizer.

    After completing this video, your final XML file will be: learning_xml.zip

    Exercise: Your goal is to create a cascading effect like that in a Rube Goldberg machine, using geometries available in CoppeliaSim. You can also arrange different orientations/positions/sizes/shapes to create more interesting behaviors. Use at least 4 objects. Here is one example from YouTube: https://youtu.be/OHwDf8njVfo?t=85.

    After solving the problem, drop the XML file in a single zipped folder called 2a_basics.zip.

    Note

    The source write-up says "geometries available in CoppeliaSim" here, even though this section is about MuJoCo — kept verbatim in case it's intentional (e.g. reused wording), but it reads like a leftover from an earlier version of this doc. Worth double-checking.

    2.2 Modeling and controlling a differential drive car (~5 hours)¶

    Material: Watch the videos and practise coding as you watch them.

    The first video covers modeling of the differential drive car: https://youtu.be/I5QvXfo8L4o

    The second video shows how to control the differential drive car: https://youtu.be/gt1fLGSggOY

    The videos use this starter file: template_mujoco_python.zip

    After completing the videos, your final code will be: 2D_Diff_Drive_Car.zip

    Exercise: Your goal is to create a steering car and write code that enables the car to move such that it traces a figure eight, by trial and error.

    After solving the problem, drop the XML and Python files in a single zipped folder called 2b_car.zip.

    Continue to Part 3: Project.
