    Part 1: Introduction to Python¶

    For this section, you will need to install Microsoft Visual Studio Code and the numpy and matplotlib packages (see items 1 and 2 in the Equipment list).

    1.1 Basics of Python (~2 hours)¶

    Material: Watch the video and practise coding as you watch it.

    https://www.youtube.com/watch?v=yutMT6NbjOU

    All the code is also available for download here: Lec01_python_basics.zip

    Exercises: After solving these problems, create a single zipped folder called 1a_basics.zip containing all Python files.

    1. If-else conditionals and inputs: Write a Python file that will prompt the user to input a year, and your code will print whether it is a leap year or not. (You will have to search how to use Python to input a number.)

    2. Computing \(\pi\) using numerical experiments.

      The value of \(\pi = 3.141592\) (6 decimals). How do you estimate this number? If you put a square of size \(2r\) and a circle of diameter \(2r\) in the rain and count the number of times a raindrop falls on the circle and on the square, then the ratio of drops falling on either shape will be proportional to the area of the respective shape. Thus:

      \[ \frac{\text{no. of drops on circle}}{\text{no. of drops on square}} = \frac{\pi r^2}{(2r)^2} = \frac{\pi}{4} \]

      You can watch this video for more information: https://www.youtube.com/watch?v=I-BC_vI4CAE.

      We can set up a numerical raindrop experiment using a random number generator in Python to compute the value of \(\pi\) using \(r=1\). Generate \(N\) random numbers for \(x\) and \(y\) between \(-1\) and \(1\). By default these points lie inside the square of side \(2\). Now for each number, check if the position \((x,y)\) lies inside the circle. If it does, then increment the counter (let's call it \(N_c\)) that keeps track of points inside the circle. For a large value of \(N\), the ratio \(\frac{N_c}{N} = \frac{\pi}{4}\). Thus \(\pi = 4 \frac{N_c}{N}\).

      Write a computer program that computes the value of \(\pi\) for a given \(N\). Then tune \(N\) such that your solution to \(\pi\) is accurate to at least 4 decimal places.

    1.2 Basics of Animation (~3 hours)¶

    Material: Watch the video and practise coding as you watch it.

    https://youtu.be/NYKemmycMm4

    All the code is also available for download here: Lec02_python_animations.zip

    Exercise: After solving these problems, create a single zipped folder called 1b_animation.zip containing all Python files.

    1. Creating a plot:

      Consider the function \(f(v)\), where \(v\) is the velocity in m/s:

      \[ f(v) = \frac{0.25 v^2}{450 + [\log(v)]^{2.5}} - 0.023v - 9.8 \]

      Write a Python file that generates a plot of \(f(v)\) vs \(v\) for velocities from 50 to 250 m/s. Be sure to include x- and y-axis labels and an appropriate title. Use a font size of at least 21 for the title. Also ensure that the x- and y-axis tick numbers use a font size of 12 or more.

    2. Python animations:

      Create an animated face of your choice — for example, a smiling face or a crying face. At a minimum, you need to include:

      a. At least one patch object (e.g., Circle, Rectangle, Polygon).

      b. At least one moving object, using the pause() command in a loop.

      c. At least one line object, using the Line2D command.

      Here are some example faces created in my robotics course: http://youtu.be/hkML3tLI3IQ.
