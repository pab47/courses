    Part 2: Motion Planning on Hardware¶

    Equipment List for Hardware¶

    Not all of these are free.

    1. Microsoft Visual Studio Code for Python. Download and install from Microsoft Visual Studio Code. Set up Python using this video and test a simple script the same way it's shown there: youtu.be/9o4gDQvVkLU.
    2. Mobile robot with mecanum wheels. A MentorPi M1 mobile robot with a Raspberry Pi (at least 4 GB RAM), an RGB-D camera, and a lidar.
    3. Connecting to and running the Raspberry Pi. A VNC viewer (free for 30 days) if you want to access the robot from your own computer. If you'd rather not use a VNC viewer, you'll need a monitor, keyboard, an HDMI-to-mini-USB cable, and a mouse to access the Raspberry Pi directly.
    4. Vibe coding with LLMs. It's highly recommended that you use LLMs (ChatGPT, Gemini, Claude, etc.) to vibe code. Vibe coding is a style of software creation where you use natural-language prompts to direct an LLM to write, fix, and build code, rather than typing it yourself line by line. You don't need a paid version of any LLM — the free tier is enough.

    General advice: break the problem down into simple tasks, then assign the LLM to program each task one at a time. Run multiple tests after each task to make sure the output does what you expect, and save your working code before you ask the LLM to add more features.

    Accessing the Raspberry Pi¶

    You can access the Raspberry Pi in two ways:

    1. From your own computer. Download and install a VNC viewer, then get the IP address, username, and password of the Raspberry Pi from us.
    2. Directly on the Pi. Connect the Pi to a monitor with an HDMI-to-mini-USB cable, and use a wireless keyboard/mouse combo.

    Running the Robot¶

    Power the robot using the switch on top. On the Raspberry Pi, open a terminal and run:

    cd Desktop
./run.sh

    This takes you to the folder containing the files you'll modify. To run the test file:

    python3 template_mecanum.py

    This displays the lidar and camera views on screen, prints the robot's x, y, theta position, and moves the robot. You'll modify this file to implement autonomous navigation.

    Writing and Transferring Code¶

    You can modify template_mecanum.py directly on the Raspberry Pi, building on the work you already did there. Alternately, you can edit the file on your own computer and transfer it to the Pi using FileZilla.

    FileZilla needs the Pi's IP address, username, and password, and connects on port 22. On the left side of the FileZilla window are your computer's files; on the right are the Pi's files. Navigate to:

    /home/pi/docker/tmp/template_mentorpi

    and drag and drop files from your computer to the Pi.

    Exercises on Hardware¶

    Follow the same progression as Part 1 to develop and deploy code on hardware:

    1. Start simple: use only vx, vy control with the lidar for obstacle avoidance.
    2. Once that works, change the drive mode (e.g. add wz) and/or switch to the camera.
    3. Build up more complex behavior strategically, saving old working code as you go before adding new features.
    4. Take plenty of photos and videos of your robot in action — you'll want them later (including for the optional write-up).
